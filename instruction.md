## Hospital Management System — Requirements Summary

Four types or user
Admin, Doctors, Receptionist, Patients


1. A seed credentials for admin
2. After login with seed credentials admin should be able to create doctors and receptionist credentials. 
3. Admin should be able to create departments with necessary details. 
4. Admin should be able to assign doctors to the specific departments. 
5. Doctors and receptionists can update their passwords after login with admin created credentials. 
6. Admin dashboard shows users based on roles, departments, total patients counts, reviews. 
7. Admin can perform crud operations on users, departments. 
8. A general user schema for admin, doctors and receptionist. 
9. A separate registration schema for patients with nid and phone number. 
10. Doctors should be able to view assigned department, create and edit own appointmentment times, 
view patients appointments, create, edit and view patients history, create prescriptions etc.  
11. Receptionists can register patients, set up appointments etc. 
12. patients can see own profile and history.
