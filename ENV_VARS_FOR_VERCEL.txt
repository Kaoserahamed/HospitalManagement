=================================================
QUICK SETUP STEPS
=================================================

1. ✅ CODE PUSHED TO GITHUB
   Repository: https://github.com/Kaoserahamed/HospitalManagement

2. 🗄️ SETUP DATABASE (Choose one):
   
   Option A - PlanetScale (Fastest):
   → Go to: https://planetscale.com/
   → Sign up with GitHub
   → Create database: hospital_db
   → Get connection string
   → Change mysql:// to mysql+asyncmy://
   
   Option B - Railway:
   → Go to: https://railway.app/
   → New Project → Provision MySQL
   → Copy connection string
   → Change mysql:// to mysql+asyncmy://

3. 🚀 DEPLOY TO VERCEL:
   → Browser opened to: https://vercel.com/new/clone?repository-url=https://github.com/Kaoserahamed/HospitalManagement
   → Click "Create"
   → Add BACKEND environment variables (above)
   → Click "Deploy"
   → Wait 2-3 minutes

4. 🔄 ADD FRONTEND ENV & REDEPLOY:
   → Go to your project settings
   → Add VITE_API_URL with your deployment URL
   → Trigger redeploy

5. 📊 INITIALIZE DATABASE:
   → Run: python setup_production_db.py "YOUR_DATABASE_URL"
   
   Or manually:
   → Connect to your database
   → Run: database/complete_schema.sql
   → Run: python backend/seed_admin.py

6. ✅ TEST:
   → Visit: https://your-project.vercel.app
   → Login: admin@hospital.com / Admin@123

=================================================
TROUBLESHOOTING
=================================================

❌ 500 Error → Check DATABASE_URL format in Vercel
❌ CORS Error → Check VITE_API_URL is correct
❌ Can't login → Run database initialization script
❌ Build fails → Check build logs in Vercel dashboard
