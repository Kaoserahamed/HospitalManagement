# ADR-0013: CI/CD Pipeline Design

## Status

Accepted

## Context

Need automated quality gates and deployments.

## Decision

Multi-stage GitHub Actions: lint, typecheck, test, build, security scan, deploy.
Container scanning and signing. Canary releases.

## Consequences

### Positive

- Consistent quality.
- Fast feedback.

### Negative / Trade-offs

- Pipeline maintenance.
- Longer run times.

## Alternatives Considered

- Single-stage: rejected; poor isolation.
