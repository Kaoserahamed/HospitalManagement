# ADR-0014: Documentation and Governance

## Status

Accepted

## Context

Need sustainable documentation and decision tracking.

## Decision

Maintain ADRs, architecture docs, runbooks, and changelog in `docs/`. Update
with each change. Code owners review.

## Consequences

### Positive

- Knowledge preserved.
- Onboarding easier.

### Negative / Trade-offs

- Maintenance overhead.
